COUCHEN - مشروع تحويل اللعبة إلى APK
1) أنشئ حساباً مجانياً على github.com وأنشئ مستودعاً جديداً (Repository).
2) ارفع كل محتويات هذا المجلد إليه (مع مجلد .github المخفي).
3) افتح تبويب Actions ثم Build APK ثم Run workflow.
4) بعد دقائق نزّل ملف COUCHEN-apk من قسم Artifacts، وبداخله app-debug.apk.
5) انقله إلى الهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة").
